# ansible-infra-bootstrap: установка 3x-ui

Ansible-плейбук для установки панели [3x-ui](https://github.com/MHSanaei/3x-ui) (Xray) на сервер с уже настроенным UFW.

## Что делает плейбук

1. Ставит вспомогательные пакеты: `curl`, `jq`, `lsof`, `tar`, `sudo`.
2. Открывает в UFW TCP/UDP-порты для Xray и порт веб-панели.
3. Скачивает официальный `install.sh` и запускает его без интерактивного ввода.
4. Задаёт порт панели, логин и пароль администратора.
5. Генерирует случайный `webBasePath` (12 символов `a-z0-9`) и применяет его.
6. Перезапускает `x-ui` и выводит адрес панели с учётными данными.

## Требования

- Control node: Ansible 2.9+ (коллекция `community.general` для модуля `ufw`).
- Целевой сервер: Debian/Ubuntu, доступ по SSH с правами root или sudo.
- UFW уже установлен и включён (плейбук только добавляет правила, сам UFW не настраивает).
- Правило для SSH в UFW уже есть.

## Файлы

```
.
├── install-3xui.yaml   # плейбук
└── vars.yaml       # переменные
```

## Переменные (`vars.yaml`)

| Переменная       | Описание                                | Пример                |
|------------------|-----------------------------------------|-----------------------|
| `xui_port`       | Порт веб-панели 3x-ui                   | `54321`               |
| `xui_username`   | Логин администратора                    | `admin`               |
| `xui_password`   | Пароль администратора                   | `change-me`           |
| `xray_ports_tcp` | Список TCP-портов для Xray              | `[80, 443]`         |
| `xray_ports_udp` | Список UDP-портов для Xray              | `[443]`               |

Пример:

```yaml
xui_port: 54321
xui_username: admin
xui_password: "{{ vault_xui_password }}"
xray_ports_tcp:
  - 80
  - 443
xray_ports_udp:
  - 443
```

Пароль лучше хранить в Ansible Vault, а не в открытом виде:

```bash
ansible-vault encrypt_string 'MySecretPass' --name 'xui_password'
```

## Запуск

```bash
ansible-playbook -i inventory.ini playbook.yaml
# с vault:
ansible-playbook -i inventory.ini playbook.yaml --ask-vault-pass
# на один сервер:
ansible-playbook -i inventory.ini playbook.yaml --limit myserver
```

В конце плейбук выведет:

```
Панель доступна по адресу: http://<IP>:<xui_port>/<случайный_путь>
Логин: ...
Пароль: ...
```

**Сохраните `webBasePath` из вывода.** Без него панель по корневому адресу не откроется.

## Особенности и ограничения

- **Идемпотентность.** Установка защищена `creates: /usr/local/x-ui/x-ui` и повторно не выполняется. Но задача с `webBasePath` при каждом запуске генерирует **новый** путь, поэтому повторный прогон меняет адрес панели.
- **Пароль в выводе.** Логин и пароль печатаются в консоль, не запускайте плейбук там, где логи попадают в общий доступ.
- **Панель по HTTP.** Панель отдаётся без TLS. Для продакшена повесьте сертификат (через настройки 3x-ui или reverse proxy) или ограничьте доступ к `xui_port` по IP в UFW.
- **Скрипт из `master`.** `install.sh` скачивается из ветки `master` без фиксации версии; при необходимости закрепите конкретный тег или коммит.
- **Порты.** Плейбук только открывает порты. Inbound-ы (VLESS, Reality и т.п.) настраиваются потом в самой панели.

## После установки

1. Откройте панель по адресу из вывода плейбука.
2. Смените пароль администратора.
3. Создайте inbound-ы на портах, которые открыты в `xray_ports_tcp` / `xray_ports_udp`.
